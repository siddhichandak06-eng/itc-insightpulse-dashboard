# 📊 ITC InsightPulse

ITC InsightPulse is a modern multi-page **Streamlit analytics platform** designed for the **ITC Personal Care Products Business (PCPB)** division.  
The dashboard helps analyze sales performance, forecast demand, monitor inventory, and optimize fund allocation through interactive visualizations and predictive analytics.
---

## 🚀 Features

### Executive Dashboard
- Real-time KPI tracking
- Revenue & sales trend analysis
- Regional performance insights
- Interactive filters and visual reports

### Strategic Planning Hub
- Demand forecasting using **Holt-Winters Exponential Smoothing**
- Inventory and stock monitoring
- Predictive business insights

### Fund Allocation Dashboard
- ROI-based budget optimization
- Scenario analysis for smarter investments
- Historical performance comparison

### Brand Analytics
Dedicated dashboards for:
- Dermafique
- Engage
- Fiama
- Savlon
- Vivel

---

## 🛠️ Tech Stack

- **Frontend:** Streamlit, HTML/CSS
- **Visualization:** Plotly
- **Database:** MySQL, SQLAlchemy, PyMySQL
- **Forecasting:** Statsmodels

---



## 🎯 Key Highlights

- Enterprise-style dark UI
- Interactive business intelligence dashboards
- Forecast-driven decision making
- Multi-brand analytics system
- Scalable and modular architecture
